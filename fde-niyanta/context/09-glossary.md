# 9. Glossary

| Word | Meaning here |
|---|---|
| **5×5 grid** | PDGMS's model of a company: five layers of authority (V1 to V5) by five stages of value (H1 to H5) |
| **V1 to V5** | Layers of authority: execution, supervision, program management, strategy, direction |
| **H1 to H5** | Stages of value: orders, experience, capacity, capability, offers |
| **Niyanta** | The PDGMS module for V5 and V4 |
| **Mimamsaka** | The PDGMS module for V3, where programs are planned and run |
| **Trinethra, Aavahana** | PDGMS modules for supervisors (V2) and for each person's daily work (V1) |
| **Commitment** | An authorisation passed down: "pursue this" |
| **Spec** | What one stage needs from the next: a sample brief is one |
| **Ticket** | A gap between plan and what happened, with its cause named |
| **Reflection** | What was learned, passed up |
| **Escalation** | A problem sent up because it needs a decision the sender cannot take |
| **Direction** | A V5 or V4 instruction about where to go, scoped to a segment, region or product. Never a task for one person |
| **Decline** | A V4's recorded choice not to apply a direction to named cases, with a reason |
| **Review by** | The date a direction must be renewed, changed or retired |
| **Validated / contradicted / insufficient** | The verdict on a direction at review: the data supports it, goes against it, or is too thin to say |
| **Low / directional / strong** | How sure a number is. Shown next to the number, never instead of it |
| **Management by exception** | Show only what is off plan or needs a decision; leave the rest quiet |
| **Level, not verdict** | Show people where they are and what would help, never a judgement or a ranking |
| **FDE** | Forward Deployed Engineer: placed inside a client to run a program and build what it needs |
| **EBITDA** | Earnings before interest, tax, depreciation and amortisation. Here: contribution minus fixed costs |
| **Contribution** | Price minus the costs that rise with every kilo |
| **Commodity / semi / specialty** | Anantha's three product segments, earning 8%, 18% and 40% contribution |
| **Good margin / strategic / filler** | The MD's three kinds of order |
| **Premium vs peers** | What an account pays against others buying the same yarn |
| **Coverage** | How much of an account's buying has a peer to compare against |
| **Denier** | Weight in grams of 9 km of yarn. `150/48` is 150 denier, 48 filaments |
| **Lustre (SD, BR, FD)** | Semi-dull, bright, full dull |
| **MX** | Mixed lustre. Cannot share a changeover |
| **Dope-dyed** | Coloured in the melt, so coloured all the way through |
| **Changeover** | Switching a line from one yarn to another |
| **Colour-family write-off** | Yarn thrown away while a line clears one colour family for another |
| **Campaign** | Running orders for a special polymer together once enough are booked |
| **Route** | The stages an order passes through: `EXT`, `TX`, `TW` |
| **Idle, no orders** | A line ready to run with nothing to run |
| **Promised date / predicted date** | What the customer was told / what Aditya's model expects |
| **Lead, MQL, SQL, Opportunity** | Early stages of winning a customer; see `04-the-yarn-plant.md` |
| **GRS** | Global Recycled Standard, a certificate Anantha does not hold |
